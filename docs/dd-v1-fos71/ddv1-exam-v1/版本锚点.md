# 版本锚点怎么读（交接包与仓内文档共用）

| 锚点 | 在哪 | 怎么读 |
|---|---|---|
| **本目录内容的版本** | 仓内 | `git log -1 --format=%H -- docs/dd-v1-fos71/ddv1-exam-v1/` ⇒ 即**本文件所在提交** |
| **交接包的版本** | 交接包（zip）内 | `版本-SHA.txt` ＝ **打包时远端分支 head**（接收方按它 checkout） |
| **基线** | 交接包内 | `基线-SHA.txt` ＝ `abc462747e99171415dc405e735773fd9d1335d1`（本版改动前的起点） |
| **本版提交清单** | 交接包内 | `本版提交清单.txt` ＝ 基线..head 的**全部**提交（逐条 title），可逐条核对，无手抄 sha |

★ **自核（一条命令）**：

```bash
# 仓内文档目录
cd docs/dd-v1-fos71/ddv1-exam-v1 && sha256sum -c SHA256SUMS

# 交接包（解包后）
sha256sum -c SHA256SUMS
```

★ `SHA256SUMS` **不含自身**（无自指循环）⇒ 改了任何文件都要重算，否则接收方自核会出 1 条 FAILED。
