## 3. 刘江 Windows 最短指南（5 步）

1. **装环境**：`安装并启动.ps1`（PowerShell）或 `点击开始-仓颉FOS.bat`；先跑 `python tools\doctor.py`（三个实测坑见交接文档 §2）。
2. **登记材料库**（**材料必须在仓库外**）：把经授权的基础材料快照放到仓库外的一个目录，登记时记下**受控本地路径 ＋ 清单指纹**。
3. **生成考场契约**：`python tools\dd_team_channel.py contract-template --out "<考场契约.json>"` ⇒ 填写真实尽调清单与**标准答案包**的位置（★ 标准答案包**只按 SHA256 解析**，**禁按文件名**）。
4. **开考前预检**：`python tools\dd_team_channel.py preflight --contract "<考场契约.json>"` ⇒ 读 `status`：**0 = 具备正式评分条件**；非 0 ⇒ 按报告列的缺项补齐（**不要**跳过）。
5. **组包 → 答卷 → 阅卷**：
   ```powershell
   python tools\dd_team_channel.py run       --contract "<考场契约.json>" --out "<输出目录>"
   python tools\dd_team_channel.py answer    --bridge-json "<输出目录>\尽调结果-*.json" --out "<机器答卷.json>"
   python tools\dd_team_channel.py grade     --contract "<考场契约.json>" --answer "<机器答卷.json>"
   ```
   ★ `--bridge-json` **支持目录/通配**（PowerShell 不做通配展开，CLI 自己解析）。

★ **主体识别不确定时**：在契约里声明 `entity_scope`（`scope_mode=SINGLE_ENTITY`＋`entity_ids`）⇒ `run --contract` 会把它落到**未指名主体**的义务上（已指名的义务**不动**）。★ 契约是**按场次**的 ⇒ 换库或换声明时，旧的 `CONTRACT_SCOPE` 会被**替换**并如实报「替换 N 条」。
