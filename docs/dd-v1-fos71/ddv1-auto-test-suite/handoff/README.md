## 4. 三场合成考试读数

| 考试 | 场景 | 题数 | 覆盖 | 总分 | 状态 | 安全闸 |
|---|---|---|---|---|---|---|
| **A** | 基础功能 | 3/3 | 1.0 | **96.67** | LOW_CONFIDENCE | PASS |
| **B** | 复杂业务（多主体/跨年度/多文件/缺料/相对期间/并列多义务/Gold 歧义） | 9/9 | 1.0 | **85.43** | SCORED_PARTIAL | PASS |
| **C** | 完整 42 题（41 份不同材料，三轴互不同余） | 42/42 | 1.0 | **100.0** | SCORED | PASS |

- **A 的 LOW_CONFIDENCE** 是**样本量标注**（义务条数 < 30 ⇒ 标注样本量不足，**分数照给**），不是「未评分」。
- **B 的 SCORED_PARTIAL** 是**如实分层**：Gold 歧义 1 条 ＋ 缺料 1 条，**分母保留全卷**。
- **C 的 100.0** 建立在**非退化夹具**上（41 份不同材料；题目落在互不相同的「主体×类型×年度」组合上）——
  有 `test_fixture_c_is_not_degenerate` 守着，**不是**同余夹具刷出来的满分。

## 5. 本轮修的东西（**这是给刘江看「机器自己发现并修好了什么」**）

| 编号 | 活缺陷 | 真实后果 | 修复 |
|---|---|---|---|
| **D1** | 多主体分簇 ID 与标准答案对不上 | **刘江那次「分数出不来」的根因** | 引入「权威 ID（库侧）」概念；分簇 ID 降级为子视图；阅卷按权威 ID 归并 |
| **D2** | 题号在答卷里丢失 | 题级覆盖**恒为 0** | 按 `item_uid→item_no` 把题号补回义务与答卷 |
| **D3** | 交付件数两个口径（7 vs 46） | 阅卷口径分歧 | 答卷同时给出两个口径；阅卷以**并集**为准（保守） |
| **D4** | 并列连接词「和/且/及」未实现 | 一条题里的**第二类要求被静默吞掉** | 受控拆分（**两侧都能解析出材料类型才切**），负例锁「涉及/至少/有且仅有」 |

外加 **3 处「假绿」**（详见 `WP0-AUDIT.md`）：G1 计数静默成 0、门禁状态语义误判、交接包路径不可达。

> ★ 四个缺陷**都补了永久回归测试** ⇒ 以后再犯会被 CI 直接抓住。
